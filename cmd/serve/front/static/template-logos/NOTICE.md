Notes:

- **Memos.** The original file picks its colour with a `prefers-color-scheme` style, which follows
  the operating system rather than checkship's theme. `memos.svg` and `memos-dark.svg` are the same
  file with that style removed and the mark filled with the two colours it sets itself: `#262b2b`
  (light) and `#eae5d8` (dark).
- **Vaultwarden.** The icon is drawn in black, so dark mode shows the project's own white icon.
- **Gotify.** The logo is licensed under CC BY 4.0; the template drawer credits it.
- **Mailpit.** The original draws its envelope white with an inline style, so it vanishes on a
  light ground. `mailpit-dark.svg` is the file as published; `mailpit.svg` is the same file with
  that style removed, so the envelope takes the colour the file declares itself (`#2d4a5f`).
- **MariaDB.** The Foundation supplies both files: `mariadb.svg` is its `dark` logotype (dark
  text, for light grounds), `mariadb-white.svg` its `light` one (white text, for dark grounds).
- **Directus.** The project names its files after the ground: `logo-dark.svg` (navy, for light
  grounds) is `directus.svg`, `logo.svg` (white, for dark grounds) is `directus-white.svg`.
- **Centrifugo.** Its dark grey ring has no light variant, so dark mode draws it on a white plate.
- **Valkey.** The mark is navy and the project publishes no light variant: in dark mode checkship
  draws it on a white plate rather than recolour it.

The files are shown with `<img>`, so any script in an SVG never runs.
